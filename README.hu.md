# Szia, István vagyok 👋

Budapesti senior Java backend fejlesztő vagyok, több mint 19 év tapasztalattal —
a Java 1.4-től és a J2EE alkalmazásszerverektől a Kubernetesen futó Spring Boot microservice-ekig.
A backend fejlesztés áll hozzám a legközelebb, de szívesen foglalkozom DevOps feladatokkal is,
szabadidőmben pedig kisebb fejlesztői eszközöket írok Go, Rust és Python nyelven.
